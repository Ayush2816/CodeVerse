## 🌟 About The Project

CodeVerse is a full-stack social networking platform designed for developers.  
Users can create professional profiles, share posts, interact with other developers, and explore GitHub repositories.

This project was built using the MERN Stack and focuses on authentication, API development, state management, and responsive UI design.

---

## ✨ Features

### 👨‍💻 Developer Profiles
- Create and customize developer profiles
- Add skills, experience, and education
- Showcase GitHub repositories

### 🔐 Authentication System
- Secure JWT Authentication
- Protected Routes
- Login & Registration System

### 💬 Social Features
- Create posts
- Like & Comment on posts
- Developer interactions

### 🌐 GitHub Integration
- Fetch user repositories
- Display GitHub profile activity

### ⚡ Additional Features
- RESTful API Architecture
- Responsive Design
- Redux State Management
